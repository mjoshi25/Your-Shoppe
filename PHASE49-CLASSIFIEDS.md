# Phase 49 – Classifieds & second-hand products

## Included
- Public approved classified listings with keyword and city filters.
- Authenticated seller submission with category, description, location, contact, optional image URL, product condition and asking price.
- Mandatory admin approval; PENDING listings are not public.
- Seller's own listing status page.
- Admin approve/reject/suspend moderation.
- MongoDB collection: `community_listings` (type `CLASSIFIED`).

## Notes
This first release is enquiry/contact based. It does not create marketplace cart orders, escrow, shipping, payment collection, sold-state workflow, in-app buyer-seller chat or direct Cloudinary upload.
